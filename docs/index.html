Overview

SAGECO EVERGREEN v3.0 transforms Uganda's real estate landscape with 10 AI-powered feature modules. Built on Supabase (PostgreSQL), Base44 serverless functions, Next.js web, and native Android (Kotlin + WebView), the platform serves property buyers, sellers, brokers, and eco-investors across Africa.

Security

  • Row-Level Security (RLS) on every table
  • Owners can read/write their own records
  • Brokers can read assigned property records
  • Admins have full access
  • Public read access for verified property listings only

Android App

The Android app exists in two forms:

1. WebView Wrapper (sageco-evergreen-app repo)

Java WebView that loads https://sageco-evergreen.vercel.app/?app=true. Includes App Mode components (AppHeader, AppModeProvider, AppModeStyles) that adapt the web app for mobile. Built via GitHub Actions to signed APK.

2. Native Kotlin App (property-masters repo)

Jetpack Compose with direct Supabase integration. 5 tabs: Properties, Brokers, Bookings, Profile, Settings. Will be extended with v3 features: drone upload, AI chat, escrow payments, investment dashboard, passport viewer, site visit camera.
